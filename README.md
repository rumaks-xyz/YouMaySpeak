## Description

In vanilla Morrowind, if you stand within a certain radius of an NPC for half a
second, they will say a random "Hello" voice line. This means that when walking
through a city, basically every NPC will stop what they're doing to say
something to the player, which gets annoying very quickly. This simple mod
changes this so that these lines only trigger for the NPC you're actively
looking at.

By default, the mod applies to every NPC with a Hello AI value of 30 or below,
which covers most Morrowind NPCs, save for certain merchants and quest givers.
You can change this threshold in the mod's settings.

## Uninstalling
Before uninstalling this mod, please go into its settings and set "Enable mod" to "No". This will prevent any permanent effects on the save file.
